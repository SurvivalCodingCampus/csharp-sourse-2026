### Lamda " => "
`` L: 매개변수, R: 실행할 코드 ``

```aiignore
ex.
```

### DTO & Mapper
- 잘못된 서버 형식이 다른 Json으로 보내도 앱의 터짐 방지
- DTO(Data Transfer Object):  JSON을 담아중간 전달 객체
- Mapper: DTO를 사용하는 Model로 변환

```aiignore
Json > DTO > Mapper를 거쳐 Model로 
ㄴ> DTO는 전부= nullable
ㄴ> Model은 non-nullable
```
```aiignore
?(nullable, null 허용) · ??(null이면 오른쪽 값 대신 사용) · !(null 아님을 컴파일러에 확신시킴)
```
