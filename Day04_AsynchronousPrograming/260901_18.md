## 📝 과제 정보

- **교육 주제**: 비동기 프로그래밍
### 동기 프로그래밍 S**yncPrograming**

코드 순서대로 실행

작업이 완료되기 전엔 프로그램이 중단 될수 없음

모든 작업은 이전의 작업이 완료 될때 까지 기다여야 함

### 비동기 프로그래밍 AsynchronousPrograming

작업 완료를 기다리지 않고 다른 작업을 시작할 수 있게 하는 허용 방식

메인 스레드를 막지않는 것이 특징

예를 들어서 다운로드 중에도 사용자는 다른 작업이 가능함

앱 실행 중에 다른 앱으로 가도 버벅이지 않음

#### async - await

async - await 는 비동기 코드를 작성할 때 더 깔끔한 코드를 제공한다.

await 키워드는 해당 Task 가 끝날 때까지 함수 실행을 기다린다.

ContinueWith() 를 활용한 콜백을 대체 하는 방식으로 간편함

ContinueWith(): 선행 Task가 끝난 뒤 실행할 후속 작업을 등록 하는 메서드

비동기 코드를 동기 코드처럼 순차적 활용이 되어서 콜백 지옥 헤결에 도움을 줌

try - catch를 통한 에러 처리가 쉬움

### 동시성 **Concurrency**

여러 작업이 논리적으로 동시에 실행 되는 것 처럼 보이는 개념 (싱글 코어)

사분할 방식으로 여러 스레드를 활용해 동시성을 구현

과거 싱글 코어 PC 환경에서 주로 활용

### 병렬성 **Parallelism**

여러 작업이 물리적으로 동시에 실행 (멀티 코어)

멀티코어 환경에서 실제로 여러 스레드가 병렬로 실행

현대의 멀티 코어 PC 환경에서 많이 사용

### 스레드 Thread

운영체제에서 CPU가 작업을 처리하는 하는 최소 단위를 말한다.

멀티 스레드는 실행 흐름을 여러개로 한다.

동시 작업을 여러개로 하여 시간이나 자원을 절약할 수 있다.

스레드 프로그래밍은 하나의 프로세스 안에서 여러개의 일을 동시에 하게 만드는 것을 말한다.

단점으로는 동시에 일을 하기 때문에 스레드가 같은 일을 하다가 충돌이 날 수가 있다.

### 콜백 CallBack

콜백은 다른 함수의 배개변수로 전달 되어 특정 작업이 끝나거나 조건이 맞을 때 나중에 호출 되는 함수

#### 콜백 기준의 동기화 방식의 문제

코드의 깊어지고 관리가 어려움

콜백 지옥

- (모든 콜백을 고려하여 프로그래밍을 해야함)
- (여러 비동기 작업이 순차적으로 의존성을 가질때 콜백 함수들이 중첩되어 코드의 가독성과 유지보수성이 급격히 저하)

디버깅이 어려움

병렬 처리의 어려움

``` csharp
public class AsyncExam
{
	public void FetchData(Action<string> onSuccess)
	{
	Console.WriteLine("데어터를 가져오는 작업 시작");
	//실제 비동기 작업 대신 지연을 사용
	Task.Delay(3000).ContinueWith(task =>
	{
		string data = "데이터";
		onSuccess?.Invoke(data); //작업 완료후 콜백 호출
	});
	Console.WriteLine("데이터 가져오는 작업 비동기적으로 시작");
}
```
