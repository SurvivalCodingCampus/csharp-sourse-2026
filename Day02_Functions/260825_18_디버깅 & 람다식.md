## 배운내용

### 람다식과 함수

- 변수에 대입 가능한 객체를 1급 객체 (first class object, first class citizen) 라고 한다.

- 대표적인 1급 객체 : 값, 인스턴스, 함수
- - 함수와 메서드의 차이 : 메서드는 클래스에서 속하고 조작하는 일종의 함수라 할수 있지만 메서드에겐 이름이 있고 함수에게 이름은 중요하지 않다.(익명 함수(Anonymous functions)
    도 존재)
#### 람다 (lambda)
```csharp
// 함수
int add(int a, int b)
{
    return a + b;
}
int Add(int a, int b) => a + b;
// 람다식 (함수 내용을 바로바로 정의해서 사용가능)
Func<int, int, int> add = (a, b) => a + b;
```

#### 함수형 프로그램
- C#는 객체 지향과 함수형 프로그램의 특징을 모두 제공하는 멀티 페러다임 언어.
- 함수형 프로그램은 자료처리를 수학적 함수의 계산으로 취급하는 프로그래밍 패러다임이고 가변데이터를 멀리하는 특징을 가진다.
##### 고계 함수(Higher - order fuction)
- 함수를 다루는 함수(다른 함수를 파라미터로 받음)
- 일반적인 데이터를 받는 1차 함수와 다르게 고계 함수는 함수를 데이터 처럼 취급
- C#의 LINQ에선 제공 되는 고계 함수
```csharp
//where: for와 if 조합, 조건에 맞는 인스턴스 또는 값 가져옴
//select: 조건에 맞는 값을 그대로 가져옴
//ToList: 주로 List 형태로 변환하여 사용
//ToHashSet: 자료구조 Set으로 변환
//Any: 특정 조건을 충족하는 요소가 있는지 검사
//List<T>.ForEach: 배열이나 목록의 모든 항목을 순서대로 쉽게 확인 처리
//Aggregate: 반복 요소를 줄여 가면서 결과를 만들 때 사용
```
