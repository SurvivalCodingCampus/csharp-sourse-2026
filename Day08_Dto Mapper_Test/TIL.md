역직렬화와 DTO
역직렬화(Deserialization)는 클라이언트가 보낸 JSON 등의 데이터 포맷을 자바 객체(DTO)로 변환하는 과정

역직렬화 (Deserialization): JSON 문자열이나 외부 데이터를 DTO 객체로 변환 하는 과정입니다 (예: 클라이언트 요청 → 서버). 
직렬화 (Serialization): 자바 객체(DTO)를 JSON 문자열로 변환하는 과정입니다 (예: 서버 응답 → 클라이언트).
DTO (Data Transfer Object): 계층 간 데이터 교환을 위해 사용하는 순수한 객체(POJO)로, 비즈니스 로직을 포함하지 않습니다.


**
동작 방식 (Spring & Jackson 기준)스프링 부트에서 @RequestBody를 사용해 JSON 요청을 받으면 내부 라이브러리(Jackson)가 역직렬화를 수행합니다.
기본적으로 기본 생성자와 Getter, 혹은 @JsonProperty나 생성자를 통해 DTO 필드에 값을 바인딩합니다.
