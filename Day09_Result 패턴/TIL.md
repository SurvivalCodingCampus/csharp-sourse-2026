`<>`

Result Pattern: 여러가지 성공과 실패를 처리하기 용이한 패턴
서버에 데이터 요청시 예상되는 상황
성공(Success)/ 실패(Error) : 네트워크 미연결, 네트워크 불안정으로 타임아웃, 논리적 오류값, 런타임 에러, 예외 상황 등
try - catch의 예외 처리로는 여러 실패 처리에 부적절

실제 코드
//성공: 데이터 정보를 담는 객체 정의
public sealed record Success(TData data) : Result<TData, TError>;
//실패: 에러 정보(예: Exception, String)를 담는 객체 정의
public sealed record Error(TError error) : Result<TData, TError>;

필요한 클래스 종류
sealed: 타입 봉인 효과 (enum하고 비슷한 효과 + 다른 객체의 참조를 가질 수 있다)
record: 불변, 동등성 비교(Equals, HashCode), ToString 재정의 횩과를 가짐
